# 🌟 Comment Star Rater

An interactive web application that performs client-side sentiment analysis on user comments, converting text reviews into 1–5 star ratings without external API dependencies or network calls. Built with HTML5 Canvas, modern CSS3 transitions, and vanilla JavaScript.

### Key Features
* **Client-Side Sentiment Engine:** Tokenizes text, evaluates weighted positive/negative word lexicons, handles negations (e.g., "not bad"), and applies sentiment intensifiers to compute star ratings.
* **Falling Stars Canvas Animation:** Interactive particle physics engine built with HTML5 Canvas and `requestAnimationFrame`.
* **Interactive UI & Filtering:** Staggered card animations, real-time score distribution charts, sentiment status badges (Positive, Neutral, Negative), and rating filter chips.
* **Theme Toggle:** Supports dark and light modes with CSS custom properties.
